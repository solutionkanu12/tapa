# Wallet brand icons

Brand marks for the wallet picker.

Source: [`@web3icons/core`](https://github.com/0xa3k5/web3icons) v4.0.53, MIT
licensed. Extracted from the package's `svgs/wallets/branded` set and copied
here so the app does not carry the full icon library as a dependency.

Each file is unmodified apart from removing the library's own `class`
attribute.

Wallets without a file here fall back to a lettered badge in the picker, unless
the wallet announces its own icon over EIP-6963 at runtime, which takes
priority over everything in this directory.

Currently missing: MiniPay, Valora, Uniswap Wallet.
